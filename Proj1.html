Project Overview

[ Excel Dashboard Placeholder ]

At IntouchCX, I designed and implemented a centralized operational hub that bridged the gap between telephony data and workforce management. By automating the flow of information, we transformed how leadership interacted with intraday performance metrics.

The Problem

Operations teams were spending over 15 hours per week manually downloading CSV files from Five9 and Assembled. By the time the data was aggregated in Excel to check agent occupancy and Service Level Agreements (SLAs), the information was already outdated. This lag prevented leadership from making rapid, intra-day staffing adjustments during unexpected peak call volumes.

Data Architecture & Workflow

To eliminate manual downloads, I designed an automated data pipeline. By utilizing APIs, raw telephony and scheduling data is extracted, transformed to ensure matching Agent IDs, and loaded into a centralized structure visualized in Looker Studio.

The Solution

I developed a dynamic, interactive dashboard using Looker Studio tailored for Operations Managers. Key features included:

  • Real-Time Refresh: Metrics are updated every 5 minutes via live data connectors.
  • Unified Metrics: Blended Handle Time and Wait Time data with Scheduled vs. Actual Adherence.
  • Threshold Alerts: Conditional formatting highlights when service levels drop below 80%.
